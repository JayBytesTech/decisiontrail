# Roadmap: DecisionTrail

## MVP Requirements

- Create decision records
- Sign up, sign in, and sign out
- View decision records
- Edit decision records
- Delete or archive decision records
- Search decisions
- Filter decisions by project, status, and tag
- Copy a decision as Markdown
- Download a decision as a `.md` file
- Deploy a working version
- Complete documentation set

## Nice-To-Have Features

- Decision templates
- Better tag management
- Project color labels
- Keyboard shortcuts for search and creation

## Post-MVP Ideas

- GitHub repository integration
- ADR file export
- Public read-only decision pages
- Team comments
- Multiple workspaces
- Decision timeline
- Superseded decision links

## Known Limitations

- The MVP uses a simple project text field instead of a project table.
- The deployed portfolio demo will use a controlled demo account instead of open public sign-ups.
- Search may start as simple database or client-side filtering before full-text search.
